# Changelog

## 0.2.7

- Publish the standalone project under the MIT license.
- Resolve launcher symlinks so Homebrew installations find the native core.
- Add portable source builds, release packaging and installation documentation.

- Split Hardware into frequency and temperature sections with individual charts.

- Add adaptive overview charts and a separate process table.

- Read ThermalService through a bounded HiShell command channel.
- Show RAM and Swap used/total and improve refresh controls.
- Preserve missing data and distinguish GPU memory from GPU utilization.
